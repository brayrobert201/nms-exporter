Big Planter – Harvest All

 October 18, 2020October 17, 2020 - Leave a Comment 

If you’re tired harvesting plants one by one and don’t like biodome (or can’t use it – in a freighter base, for example), then this mod is for you!

Adds “Harvest All” action to big planter.

You can harvest all plants at once from big planter by looking at planter center and executing action “Harvest All”, or you can harvest old way – by looking at plant you wish to pick up.

Installation:

Copy .pak file from downloaded archive to %GAMEDIR%\GAMEDATA\PCBANKS\Mods directory.

If there is no Mods directory – create it.

If there is DISABLEMODS.txt file in %GAMEDIR%\GAMEDATA\PCBANKS directory – remove it or rename it to simething else (ENABLEMODS.txt, for example).

Uninstallation:

Remove BigPlanterHarvestAll.pak from %GAMEDIR%\GAMEDATA\PCBANKS\Mods directory.

This mode changes MODELS\PLANETS\BIOMES\COMMON\BUILDINGS\PARTS\BUILDABLEPARTS\TECH\CUBEROOM_PLANTERMEGA.SCENE.MBIN, so any mod changing this file will be incompatible.

Additional step, when merging/rebuilding mod with AMUMMS:

Copy MODELS directory from downloaded archive to ModExtraFilesToInclude directory in AMUMSS top dir.

Mod assembled with AMUMSS, lua file included.
